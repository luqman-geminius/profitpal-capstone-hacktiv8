# ProfitPal — E-Commerce & UMKM True-Profit & Return Analyzer

Dashboard analitik interaktif berbasis **HTML5, CSS3, dan Vanilla JavaScript (ES6)** tanpa framework eksternal untuk membantu pelaku UMKM Gen-Z dan penerus bisnis keluarga menghitung profit bersih aktual (*True Net Profit*) serta mendeteksi kebocoran biaya iklan dan retur barang.

## Fitur Utama
- **Real-Time CSV Grounding:** Mengolah langsung 100 baris transaksi dari `dataset_umkm_profitpal_100.csv` (12 SKU).
- **Hero Profit Health Score & 4 KPI Cards:** Menghitung Omzet Kotor, True Net Profit, Total Biaya Iklan, dan Kerugian Retur secara dinamis.
- **Dual-Hemisphere Mirrored Wave Chart (SVG):** Membandingkan omzet & profit bersih (gelombang atas) terhadap biaya iklan & retur (gelombang bawah) per SKU.
- **Audit Log & Modal Detail:** Tabel 4 kolom dengan pencarian cepat, *sorting*, *pagination* 5 baris per halaman, dan pop-up detail 17 atribut transaksi.

## Cara Menjalankan
Buka melalui tautan **GitHub Pages** pada bagian *About* di sebelah kanan repositori, atau jalankan menggunakan *local server* (misalnya `python3 -m http.server 8000`) agar pemuatan file CSV berjalan optimal.
